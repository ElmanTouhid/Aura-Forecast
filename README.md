## ✨ About

Many people choose perfume by season: light citrus for summer, rich vanilla and amber for winter, clean aquatic scents for the monsoon. **Aura Forecast** does this for you. It checks the current weather, works out the season and mood, and recommends fragrances that fit.

## 🚀 Features

- 🌡️ **Live weather.** Gets the current temperature, humidity and conditions for your location.
- 🍂 **Season-based suggestions.** Maps the weather to a season and recommends matching perfumes.
- 🔍 **Search.** Finds any perfume by name, note or house.
- 🎛️ **Filters.** Narrows results by season or scent family.
- 🧪 **Perfume details.** Shows notes, character and when to wear each scent.
- ❤️ **Favourites.** Saves perfumes you love; they stay after a page refresh, thanks to localStorage.
- ⏳ **Loading, error and empty states.** Gives clear feedback at every step.

## 🔌 APIs Used

Both APIs are **free, open and need no API key or sign-up**.

| API | Purpose |
|-----|---------|
| [Open-Meteo](https://open-meteo.com/) | Current weather data |
| [Scento Perfume API](https://www.scento.com/developers) | Perfume search, notes, seasons and similar scents |
